# Oficina Inteligente Cuba

La aplicación ejecuta procedimientos por servicio y conserva el producto, sus documentos, cálculos, revisión y entrega. Incluye 143 servicios del catálogo y la ampliación para nuevos actores cubanos.

- Web: https://jbc76030-create.github.io/Web/oficina/
- Aplicación: https://jbc76030-create.github.io/Web/oficina/app/
- Código: https://github.com/jbc76030-create/Oficina-Inteligente/tree/main/suite

En Android u ordenador abrir la aplicación, registrar el cliente y su contrato, crear el pedido y subir documentos. En Taller de servicios configurar WebLLM u Ollama, seleccionar modelo y preparar una respuesta real. Elaborar, revisar y exportar el paquete para el cliente. WebLLM necesita WebGPU y descarga inicial; la memoria y calidad dependen del modelo y equipo. No se incluyen pesos de IA.

Para la consola local instalar Python 3.10 o superior y ejecutar el iniciador del sistema. Instalar Ollama desde su sitio oficial y un modelo antes de trabajar sin conexión. Los lectores PDF y PPTX de la consola usan dependencias opcionales; CSV, Word de salida, tablas y cálculos funcionan con la biblioteca estándar. La extracción OCR de la consola requiere Tesseract y los PDF pueden usar Poppler.

Para otra cuenta de ChatGPT usar CHATGPT_EMPEZAR_AQUI.txt y CONOCIMIENTO_SERVICIOS.txt. Instalar el plugin o habilidad solo si la cuenta y superficie admiten ese formato. El ZIP no traslada credenciales ni activa herramientas inexistentes.

El plan genera tareas durante el contrato. Cada cierre necesita evidencia y revisión. El éxito de negocio se mide con entregables aceptados, puntualidad, calidad y mejoras reales. Consultar GUIA_DE_USO.html e INFORME_DE_VERIFICACION.html. Los datos de la PWA permanecen en cada navegador y se trasladan mediante copias; no hay sincronización multiusuario automática.
