Antes de empezar

¿Puedo contratar un solo servicio?

Sí. Cada servicio puede contratarse de forma independiente o integrarse en un paquete definido para tu empresa.

¿Puedo trabajar desde cualquier lugar?

La web y la aplicación tienen acceso por navegador. Tras abrir e instalar la aplicación con conexión, sus registros y cálculos pueden utilizarse sin Internet. Para trasladar datos a otro dispositivo, exporta e importa una copia.

¿Cómo se comprueban los resultados?

Cada pedido conserva sus entradas, cálculos, versión, responsable y revisión. La aceptación y las mejoras se registran con evidencia; las metas se acuerdan con el cliente.

¿Cómo se trabaja con las normas cubanas?

Se consulta la Gaceta Oficial, se determina el régimen del actor y se identifican obligaciones, artículos y evidencias. El alcance depende de las autorizaciones y habilitaciones aplicables.
